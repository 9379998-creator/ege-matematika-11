# Инструкция для Perplexity

1. **Изучение контекста**: В начале любой сессии явно прочитайте файлы [AGENTS.md](AGENTS.md) и [docs/GIT_WORKFLOW.md](docs/GIT_WORKFLOW.md) через доступные инструменты чтения файлов или репозитория.
2. **Точность отчётов о состоянии**: Никогда не утверждайте, что локальные файлы на диске G:\ изменены, если была выполнена только операция через веб-интерфейс GitHub или Google Drive (и наоборот). Чётко разделяйте локальную рабочую копию и удалённый репозиторий.
3. **Подтверждение внешних записей**: Все операции создания, изменения или коммита файлов выполняйте только с подтверждениями, требуемыми инструментами среды.
4. **Режим GitHub-only**: Если работа ведётся исключительно через GitHub (без доступа к локальному диску G:\), явно сообщите пользователю, какой коммит и в какой ветке создан, и напомните, что локальную рабочую копию на Google Диске необходимо обновить командой git pull.
