# 10. Стереометрия

- **Назначение**: Геометрия в пространстве: многогранники, тела вращения, построение сечений, расстояния и углы в пространстве, координатно-векторный метод (задания 1-й и 2-й части).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
