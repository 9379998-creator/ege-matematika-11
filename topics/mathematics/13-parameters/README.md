# 13. Задачи с параметром

- **Назначение**: Аналитические методы, функционально-графические методы (в плоскостях (x; a) и (x; y)), использование симметрий, монотонности и ограниченности (задание 18 профильного ЕГЭ).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
