# 03. Тригонометрия

- **Назначение**: Тригонометрический круг, базовые и следственные формулы, преобразование тригонометрических выражений, решение тригонометрических уравнений.
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
