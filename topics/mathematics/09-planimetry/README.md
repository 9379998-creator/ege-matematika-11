# 09. Планиметрия

- **Назначение**: Геометрия на плоскости: треугольники, четырехугольники, многоугольники, окружности, комбинации фигур; задачи 1-й и 2-й части ЕГЭ.
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
