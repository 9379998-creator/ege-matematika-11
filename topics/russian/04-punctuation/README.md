# 04. Пунктуация

- **Назначение**: Пунктуация в простом предложении с однородными членами, обособленными членами (определения, обстоятельства, приложения), вводными словами и обращениями; сложносочиненных, сложноподчиненных и бессоюзных предложениях; пунктуационный анализ текста (задания 16–21 ЕГЭ).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
