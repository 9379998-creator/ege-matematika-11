# 06. Сочинение (задание 27)

- **Назначение**: Структура сочинения-рассуждения: формулировка проблемы, комментарий с опорой на исходный текст (два примера-иллюстрации, пояснения, смысловая связь и её анализ), позиция автора, собственное отношение к позиции автора с обоснованием, логика, речевое оформление, фактическая и орфографическая грамотность.
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
