# 02. Нормы современного литературного языка

- **Назначение**: Орфоэпические нормы (ударения), лексические нормы (паронимы, лексическая сочетаемость), морфологические нормы (формы слов), синтаксические нормы (грамматические ошибки, задание 8 ЕГЭ).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
