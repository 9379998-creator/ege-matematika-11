# 03. Орфография

- **Назначение**: Правописание корней (безударные, чередующиеся), приставок, суффиксов различных частей речи, личных окончаний глаголов и суффиксов причастий, НЕ/НИ, слитное, дефисное и раздельное написание слов, Н и НН (задания 9–15 ЕГЭ).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
