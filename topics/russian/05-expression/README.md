# 05. Выразительность речи

- **Назначение**: Тропы (метафора, эпитет, сравнение, метонимия, олицетворение и др.), фигуры речи (анафора, антитеза, градация, парцелляция), лексические и синтаксические средства выразительности (задание 26 ЕГЭ).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
