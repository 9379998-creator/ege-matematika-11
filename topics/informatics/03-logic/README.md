# 03. Математическая логика

- **Назначение**: Базовые логические операции (конъюнкция, дизъюнкция, импликация, эквивалентность, инверсия), построение и сопоставление таблиц истинности, логические уравнения и множества/отрезки (задания 2, 15).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
