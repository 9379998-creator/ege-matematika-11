# 02. Системы счисления

- **Назначение**: Позиционные системы счисления, перевод чисел между системами, арифметика в n-ичных системах, позиционная запись больших чисел и уравнений (задание 14).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
