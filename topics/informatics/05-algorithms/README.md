# 05. Алгоритмизация и исполнители

- **Назначение**: Формальные исполнители («Черепаха», «Редактор», «Робот»), динамическое программирование для поиска количества программ (задания 6, 12, 23).
- **Статус наполнения**: Ожидает наполнения (структурный шаблон).
- **Примечание**: Рабочая методическая группировка, не дословный кодификатор ФИПИ.
