# Учебные направления и разделы подготовки к ЕГЭ

Репозиторий содержит материалы для системной подготовки к ЕГЭ по четырём предметам:

- [Математика (профиль)](mathematics/README.md) — 14 тематических разделов (алгебра, геометрия, матанализ, статистика, параметры, теория чисел).
- [Русский язык](russian/README.md) — 6 тематических разделов (текст, нормы, орфография, пунктуация, выразительность, сочинение).
- [Информатика](informatics/README.md) — 9 тематических разделов (кодирование, системы счисления, логика, алгоритмы, Python, электронные таблицы, сети, теория игр).
- [Обществознание](social-studies/README.md) — 7 тематических разделов (человек и общество, культура, экономика, социология, политика, право, развёрнутые ответы).

*Примечание*: структура разделов является рабочей методической группировкой, а не дословным кодификатором ФИПИ. Соответствие спецификациям ФИПИ проверяется отдельно по каждому предмету и году.
